# 进度板索引

任务明细一任务一文件，放在 `进度/`；本文件只做索引与总览，不写任务细节。

## 用法

1. 新任务：复制 `进度/example-task.md`，重命名为 `<主题>-<动作>.md`。
2. 认领：把 `owner` 改成本人/本 agent 标识，`status` 改 `进行中`，push 后开工。
3. 推进：每次有实质进展就更新正文「进展」与 `updated`；停滞超 14 天会被标黄牌。
4. 完成：`status` 改 `已完成`，补齐 `evidence`；人工复核后填 `confirmed_by` 才算关单。

## 状态枚举

`待启动` / `进行中` / `待验收` / `已完成` / `挂起`，定义与转移见 `进度/README.md`。

## 旧式单文件条目

兼容形态是在本文件写 `## [状态] 标题`，下方写 `负责: <owner>` 与日期；旧词经映射转成当前枚举。两种形态不要对同一任务重复登记，否则同一任务会被算成两条。
